# Satsang Parichay Prep

A study planner, PDF reader and quote card trainer for the BAPS Satsang Parichay exam (Feb 28, 2027).

Open the site in Safari on iPhone, tap Share, then Add to Home Screen, and it runs full screen like an app.
Each person adds their own PDF copies of the textbooks; nothing from the books is stored in this repo.
Progress is saved on each device. Use Plan > Backup to move it between devices.
